FULL-STACK

Bibliotech

Sistema de biblioteca desenvolvido para organizar usuários, livros e empréstimos.

Sobre o projeto

O Bibliotech é um projeto que reúne diferentes partes de um sistema: Front-end, Back-end e Banco de Dados.

A proposta é permitir o gerenciamento de usuários, livros e empréstimos de uma biblioteca.

Tecnologias

HTML CSS JavaScript Node.js Express Prisma MySQL

Estrutura

  • Front-end
  • Back-end
  • Banco de Dados
  • Aplicação Mobile

Como testar

  1. Acesse o repositório no GitHub.
  2. Baixe ou clone o projeto.
  3. Instale as dependências necessárias.
  4. Configure o banco de dados.
  5. Execute o Back-end.
  6. Acesse o sistema pelo navegador.
